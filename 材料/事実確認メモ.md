# 事実確認メモ（出典URLつき）

確認日：2026年10月20日
※ 料金・手数料は変わることがあるので、公開前に最後は公式ページで確認すること。

## 1. noteは無料で始められる
- 会員登録は無料。Google / X / Apple / メールのいずれかで登録できる。
- 出典：note公式ヘルプ「会員登録の方法」
  https://help.note.com/hc/ja/articles/900000936783

## 2. 収入を得る方法（収益化メニュー）
- 有料記事：1記事から値段をつけて売れる（初心者が試しやすい）
- チップ（旧サポート）：読者が100円・500円・好きな金額を応援でくれる機能
  ⚠️ 公開した記事が1本もないと、チップは受け取れない
- メンバーシップ：月額のファンクラブのような仕組み
- 有料マガジン / 定期購読マガジン：記事をまとめて売る
- 出典：note収益化メニュー（公式） https://note.com/monetization-guide
- 出典：チップ機能の案内（公式） https://note.com/info/n/n2bc95c82b99e

## 3. 手数料（noteに引かれる分） ※要確認（変わる可能性あり）
- 有料記事・メンバーシップなど：おおよそ 10%
- 定期購読マガジン：おおよそ 20%
- ＋ 決済（支払い）手数料が別にかかる
- → 正確な数字は公式で最終確認する

## 4. 広告・PRのルール（大事）
- アフィリエイトなどお金が入る記事には「PR」「広告」などの表記が必要
- 国のルール（ステマ規制）が 2023年10月1日からスタートしている
- 小さい文字や見えにくい場所ではダメ。冒頭でハッキリ書くのが安全
- 出典：消費者庁 ステルスマーケティングQ&A
  https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/stealth_marketing/
